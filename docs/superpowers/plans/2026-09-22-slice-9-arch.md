# Slice 9 — Architecture Hardening Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden architecture/security/DevOps: helmet, idempotency scoping, audit index, infra healthchecks, CI dead-code gate, contact rate-limit, transactional outbox (incremental, deploy-gated), live local verification short of migrations.

**Architecture:** All changes are additive/defensive. Outbox ships code-first with graceful fallback (direct publish when table missing); migrations are source-only (backend-patterns: applying to any connected DB needs explicit user confirmation — NEVER run `migrate deploy/push` in these tasks).

**Tech Stack:** Fastify, Prisma, Docker Compose, GitHub Actions, Turbo, pnpm.

## Global Constraints

- AGENTS.md: Zod; `req.meta`; AppError-only; French copy; no TODOs; typechecks clean; TDD. No `process.env` outside `packages/config` (use `loadEnv()`).
- NEVER run `prisma migrate deploy`, `db push`, or `db:generate` against a connected DB. `prisma validate` (read-only) is allowed.
