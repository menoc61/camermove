## Context

Current UI is poor: teal/amber palette mismatched, Select capped at 9, hardcoded max10, no live inventory, no agency comparison. True interurban = 348 agencies (70% Littoral/Centre/Ouest), Yaoundé–Douala Eco 5 500 / VIP 6-7k, homologué 17 FCFA/km, competitors LOHCE/MATOA/Travely win with agency choice + offline code + 60s payment. redBus pattern: pax = seats tapped / stepper, live seatsRemaining, hold countdown.

Theme direction: **classic black/white/grey** — editorial, high contrast, timeless like redBus print. GSAP for intro + scroll reveals + stepper micro-interactions, but strictly compositor-only.
